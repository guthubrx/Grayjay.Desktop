# Data Model: Smart Search

## SmartSearchRequest

Request received by the BlueJay backend for an international enrichment.

| Field | Type | Rules |
|---|---|---|
| `sessionId` | string | Generated by BlueJay; ties asynchronous work to one visible search. |
| `query` | string | Original user text; non-empty and length-bounded. |
| `languages` | string[] | Unique ISO language tags; capped by settings. |
| `type` | content type | Reuses the normal search type. |
| `filters` | map | Reuses normal source filters. |
| `excludePlugins` | string[] | Reuses normal source selection. |

## SmartSearchVariant

| Field | Type | Rules |
|---|---|---|
| `language` | string | Requested language tag. |
| `displayName` | string | Localized label supplied by BlueJay, not by the command. |
| `query` | string | Non-empty translated query. |
| `status` | enum | `pending`, `ready`, `error`, `cached`. |
| `error` | string? | Sanitized user-facing failure only. |

## SmartSearchResult

Wraps an existing `PlatformContent` without changing its source metadata.

| Field | Type | Rules |
|---|---|---|
| `content` | PlatformContent | Original platform result. |
| `key` | string | Canonical URL, otherwise stable platform id. |
| `languages` | string[] | One or more language angles that produced the content. |
| `originalTitle` | string | Always preserves `content.Name`. |
| `translatedTitle` | string? | Optional display enrichment in the configured user language. |

## SmartSearchTranslationCacheEntry

Persisted locally only.

| Field | Type | Rules |
|---|---|---|
| `kind` | enum | `query` or `title`. |
| `sourceText` | string | Exact original input. |
| `sourceLanguage` | string? | Optional, only when known. |
| `targetLanguage` | string | User display language or requested search language. |
| `translatedText` | string | Validated non-empty result. |
| `createdAt` | unix seconds | Cache metadata. |
| `expiresAt` | unix seconds | Query entries expire sooner than title entries. |

## Translator command contract

The command reads a single JSON object from standard input and writes one JSON object to standard output. It never receives a secret from BlueJay. It uses its own environment and Routr configuration.

Invariants:

- A query translation response contains exactly one entry for every requested language, or explicitly marks an entry as failed.
- A title translation response contains at most one result for every input key.
- Empty values, unexpected keys and invalid JSON are rejected at the command boundary.
- The backend never puts raw command stderr or provider payloads in the UI response.
