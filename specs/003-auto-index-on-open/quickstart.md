# Quickstart: Automatic Smart Analysis On Video Open

1. In Smart Analysis, select `Français` or another explicit `Generation language`.
2. Keep `Auto-generate on video open` enabled.
3. Configure the existing Smart Chapters generator command with `{url} {subtitles} {language}`.
4. Open an unindexed non-live video. Playback must begin immediately.
5. Wait for the Smart Chapters ready notification and open the subtitle source menu.
6. Verify a translated subtitle source in the selected generation language is available.
7. Reopen the same video and verify it is not queued again.
